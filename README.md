
WELT — download
WELT is a 3D CAD and BIM modeller: push/pull modelling, architecture, structure and steel, MEP, landscape, drawings and sheets, IFC/DXF/DWG exchange and rendering.

This repository holds the released programs only. Download the latest version from Releases.

Your computer	Download
Windows 10/11 (64-bit)	WELT-<version>-windows-x86_64.zip — unzip into a folder you own (e.g. %LOCALAPPDATA%\WELT) and run welt.exe
macOS, Apple Silicon (M1–M4)	WELT-<version>-macos-aarch64.zip — unzip and drag WELT.app to Applications
macOS, Intel	WELT-<version>-macos-x86_64.zip
Linux (64-bit)	WELT-<version>-linux-x86_64.tar.gz — extract into e.g. ~/.local/opt/WELT and run welt
The files named welt-<platform>.gz and latest.json are used by WELT's built-in updater; you don't need to download them.

First start
Windows: if SmartScreen shows "Windows protected your PC", click More info › Run anyway.
macOS: the first time, right-click WELT.app › Open and confirm.
Linux: you need the usual desktop libraries (libxkbcommon-x11, libGL).
Updates
When a new version is published, WELT shows a green Update button at the top right. It downloads the new version, checks its signature, installs it and restarts. You can also choose Help › Check for updates….
